## 🌟 Project Overview

**LoanScope** is an end-to-end **Financial Loan Analytics Dashboard** developed using **Power BI, SQL Server, Power Query, and DAX** to analyze loan performance, customer demographics, and default risk patterns.

The project demonstrates a complete analytics workflow including:

- Data extraction and transformation
- Data modeling
- Advanced DAX calculations
- Interactive dashboard development
- Financial risk analysis


---

# 🎯 Business Objectives

The dashboard helps organizations understand:

✅ Loan distribution across different customer segments  
✅ Default patterns and risk factors  
✅ Customer financial behavior  
✅ Credit score impact on loan performance  
✅ Year-over-year loan growth trends
